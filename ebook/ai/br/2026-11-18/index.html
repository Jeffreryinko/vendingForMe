11월 18일 AI 브리핑

11월 18일 12시 정리

오늘은 OpenAI의 새 모델 GPT-6.2와 구글의 제미나이·검색 업그레이드처럼 바로 써 볼 수 있는 소식이 많았어요. 대신 일을 해 주는 AI가 업무와 쇼핑, 의료, 법률 현장으로 넓어지고 있어요. 한편 AI 안전 검증, 보안 위협, 마이크로소프트 서비스 장애 같은 이야기도 함께 나왔어요.

첫 소식부터 읽기 ›

  1. GPT-6.2 Astra·Sol 공개, 법률 특화도 나와요
    OpenAI가 GPT-6.2 Astra와 Sol을 소개했어요. ChatGPT Work, Codex, API 등에서 전문적인 결과, 코딩, 컴퓨터 사용, 효율성이 나아지고 비용 절감 효과도 있다고 해요. 법률 특화 Astra for Law는 24개 법 분야 출시 평가에서 1위를 했어요.
  2. 제미나이가 구글 업무 도구와 더 가까워져요
    제미나이 기능이 현재 6개 국가에서 무료로 제공돼요. 새 기능은 미국부터 시작하고, 사용자를 대신해 업무를 처리하는 구글 워크스페이스 연동이 더 강해져요. 제미나이 인텔리전스도 더 많은 기기에서 쓸 수 있게 돼요.
  3. 구글 검색과 지도가 더 똑똑해져요
    구글 검색에 제미나이 4 하이드로겐이 전 세계로 들어가 더 시각적이고 직관적인 답을 줘요. 구글 지도의 Ask Maps 기능으로는 휴가 여행 계획, 경로 정보, 저장한 목록 검색을 할 수 있어요.
  4. ChatGPT 지갑으로 AI가 대신 결제해요
    ChatGPT Wallet은 ChatGPT Work, Codex, 닷츠의 AI가 사용자 승인과 기존 카드 보호 기능을 거쳐 안전하게 구매를 마치게 해요.
  5. 텐센트 Hy4 플래시, 작업 비용 95% 줄여요
    텐센트가 문서 작성, 발표 자료 제작, 자료 조사 같은 일상 업무에 맞춘 저비용 AI 모델을 냈어요. 자체 평가에서 작업당 비용이 최대 95% 줄고 만족도는 클로드 하이쿠 5.5에 가까웠다고 해요.
  6. ChatGPT가 의료 현장 업무도 도와요
    컴퓨터 사용 지원, 개선된 임상 답변, 여러 의료 소프트웨어에서 쓰는 의료 플러그인이 소개됐어요.
  7. OpenAI, 외부 전문가에게 모델 검증을 열어요
    OpenAI가 아폴로 리서치, METR, 트랜슬루스, 굿파이어에 비공개 모델, 학습 데이터, 내부 감시 시스템 접근권을 주기로 했어요. 굿파이어 인수 검토설도 있었지만 성사되지 않았고 안전성 평가 협력을 시작했어요.
  8. AI 해킹 도구가 실제 공격자 서버에서 발견됐어요
    구글이 보안 패치를 분석해 취약점을 찾고 공격 코드 생성과 실행까지 자동화한 AI 해킹 도구를 실제 공격자 서버에서 발견했어요.
  9. MS 서비스 장애 원인은 4개월 전 버그예요
    MS가 지난 7월 적용한 소프트웨어 변경의 결함이 원인이었다고 밝혔어요. 자동 복구 시스템도 연쇄 장애를 내 아웃룩 핵심 서버의 80% 이상이 응답하지 않았어요.

발표문·기사 제목과 요약만 보고 AI가 썼어요. 값·지역 같은 세부는 원문을 확인하세요.
