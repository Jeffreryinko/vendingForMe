23.1% → 17.3%

#108 · 노쇼·예약·수업

A등급

아무 연락 없을 때 노쇼 23.1%, 자동 문자 17.3%, 직접 전화 13.6%

쉽게 말하면

아무 연락이 없으면 노쇼 23.1%, 자동 문자는 17.3%, 직접 전화는 13.6%였어요. 전화가 가장 좋지만, 자동 문자도 전화 효과의 상당 부분을 거의 공짜로 가져옵니다.

브로제이로 연결

자동 알림 + 중요 회원 전화

출처

Parikh 외, Am J Med 2010 (Lobbie 요약)

A등급: 논문·정부·협회 자료예요. 상담에서 가장 자신 있게 꺼낼 수 있는 숫자입니다.

후속 문자 3가지

문제 해결형

[원장님], 브로제이 Jeff입니다.
지난번 말씀하신 노쇼 연락 방법, 해결 방법을 정리해 드려요.
미국 병원 연구에서 연락 없을 때 노쇼 23.1%, 자동 문자 17.3%, 직접 전화 13.6%였대요(Am J Med 2010).
브로제이는 이렇게 해결해요.
- 회원이 운톡 앱으로 24시간 예약·취소하고, 마감된 수업은 대기 신청해요
- 취소가 나오면 대기 회원이 순서대로 자동 예약되고 예약 알림이 나가요
빈자리와 노쇼가 줄고 전화 응대도 줄어요. 10분이면 화면으로 보여드릴 수 있어요. 편한 시간 알려주세요.

질문 해결형

[원장님], 노쇼 회원에게 직접 전화도 하세요?
미국 병원 연구에서 연락 없을 때 노쇼 23.1%, 자동 문자 17.3%, 직접 전화 13.6%였대요(Am J Med 2010).
브로제이로 이렇게 풀 수 있어요.
- 회원이 운톡 앱으로 24시간 예약·취소하고, 마감된 수업은 대기 신청해요
- 취소가 나오면 대기 회원이 순서대로 자동 예약되고 예약 알림이 나가요
자동 알림으로 1차, 중요 회원만 전화하는 방식 보여드릴까요?
