객단가·부가상품

19건

체육관 정가는 평균 165달러인데 실제 받는 돈은 100달러 정도예요. 할인·가족 요금이 쌓이기 때문이죠. 코칭이 들어갈수록 회원 1명당 매출이 커집니다.

함께 읽을 글

  • 도장·체육관: 4,594곳 데이터가 보여준 풍경
  • 함께 운동하면 오래 다닌다: 그룹 수업과 PT
  1. +28% 상승 확인 필요
    개인 락커 및 운동복 동시 결제(결합 구매) 채택률. 회원권 선택 직후 화면에 "월 1만 원 추가로 개인 락커+운동복을 이용하시겠습니까?" 팝업을 띄웠을 때의 추가 선택률
  2. 42% → 64% (+22%p) 확인 필요
    장기권(6개월·12개월) 월 환산 금액 비교 화면 노출 시 장기권 선택 비중. 1개월권 옆에 12개월권의 '월 환산 할인액'을 시각적으로 강조해 보여줄 때 회원이 스스로 장기권을 고르는 비율
  3. 18% ~ 24% 확인 필요
    신규 회원권 결제 시 '웰컴 1회 체험 PT(유료 할인)' 동시 구매율. 헬스 회원권 결제 마지막 단계에서 정가 7만 원 PT 1회를 '신규 가입 시 2만 원'으로 제안했을 때 장바구니에 담는 비율
  4. 68% 확인 필요
    락커 만기 도래자 출석 시 키오스크 화면 팝업을 통한 즉시 연장률. 출석 체크 시 키오스크 화면에 "락커 만기 3일 전입니다. 지금 바로 연장하시겠습니까?"를 띄웠을 때 즉시 결제하는 비율
  5. +90% 이상 증가 확인 필요
    일일 운동복/수건 대여비 및 생수/보충제 유료 결제 회수율. 데스크에서 직원이 "운동복 1,000원 결제하셔야 해요"라고 말하기 애매해 그냥 주던 것을 키오스크로 유료화했을 때의 부가 수익
  6. +40% 증가 확인 필요
    태닝·인바디·안마의자·리커버리존 등 유료 부가시설 이용권 판매량. 키오스크 메뉴에 부가시설 1회권/10회권을 상시 노출하여 호기심 구매를 유도하는 효과
  7. 결제 전환율 +19% 상승 확인 필요
    카드사 무이자 할부 안내 자동 노출 시 고액권(PT 30회 등) 결제 저항 감소. 100만 원 이상 결제 시 키오스크에서 무이자 할부(3~6개월)를 직관적으로 선택하게 하여 목돈 결제 부담 완화
  8. +26% 상승 확인 필요
    포인트/마일리지 잔액 화면 표시 및 즉시 차감 결제 시 재등록 유도율. 출석 등으로 쌓인 포인트를 키오스크 결제창에서 현금처럼 바로 깎아줄 때 느끼는 체감 할인 효과
  9. 34% 확인 필요
    만기 D-7 이내 회원 출석 시 '얼리버드 재등록 할인' 화면 자동 노출 전환율. 만기 직전 회원이 출석 바코드를 찍는 순간 본인에게만 보이는 재등록 10% 자동 할인 쿠폰이 뜰 때의 현장 결제율
  10. 월 50만 ~ 150만 원 추가 확인 필요
    키오스크 영수증/알림톡 내 제휴 쿠폰 발송 시 부가 매출. 결제 완료 알림톡에 샐러드·닭가슴살·스포츠웨어 제휴 링크나 센터 프로틴바 쿠폰을 넣어 만드는 부가 수익
  11. 사람 45% 누락 vs 키오스크 0% 확인 필요
    업셀링 스크립트 누락률 (사람 vs 키오스크). 바쁘거나 피곤한 직원은 추가 옵션 안내를 절반 가까이 생략하지만, 키오스크는 단 1명에게도 빠짐없이 100% 제안함
  12. $165 → $100 B등급
    정가는 평균 약 165달러인데 실제 회원 1명당 받는 돈은 약 100달러 (할인·가족 요금 등)
  13. 약 90% B등급
    체육관 거의 90%가 요금제를 2가지 이상 운영 (월 정기 회원 63%)
  14. +3% / +9.7% B등급
    회원 1명 월 지출: 헬스장 3%, 스튜디오 9.7% 증가
  15. $126~186 B등급
    대형 그룹 체육관 회원 1명당 월 매출 평균 구간 (우수 $187 이상)
  16. $288+ / $360+ B등급 · 추천
    우수 기준 회원 1명당 월 매출: 소그룹 288달러+, 1:1 PT 360달러+
  17. 4배 A등급
