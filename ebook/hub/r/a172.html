광고 문의 100건이 등록 3~6명: 새는 단계 찾기

체험·상담 · 전체

업계 기준 비율로 계산하면 광고 문의 100건이 체험 예약 5~11건, 방문 4~8건, 등록 3~6명이 됩니다. 어느 단계에서 새는지 알아야 광고비가 살아납니다.

3~6명

유료 광고 문의 100건당 예상 등록 수

세 줄 요약

  • 유료 광고 문의 100건 → 체험 예약 5~11건 → 방문 4~8건 → 등록 3~6명(Keepme, 업계 기준 비율로 계산한 예시, C등급).
  • 광고비를 늘리기 전에 문의 → 예약, 예약 → 방문, 방문 → 등록 중 어디가 약한지 봐야 합니다.
  • 문의 응대 속도, 예약 알림, 체험 후 연락이 각 단계를 지키는 도구입니다.

대표님이 광고비 50만 원을 썼고 문의가 100건 왔습니다. 등록은 4명입니다. "광고 효과가 없네" 하고 끊기 전에 봐야 할 것이 있습니다. 96명은 어디로 갔을까요?

Keepme가 북미 업계 기준 비율로 계산한 예시에서 유료 광고 문의 100건은 체험 예약 5~11건, 실제 방문 4~8건, 등록 3~6명으로 이어졌습니다. 공급사의 계산 예시라 C등급이지만 구조는 어느 센터나 같습니다. 문의 → 예약 → 방문 → 등록, 네 단계마다 손님이 빠져나갑니다.

어느 단계가 약한지에 따라 해결이 다릅니다. 문의 → 예약이 약하면 응답이 느린 것이고, 예약 → 방문이 약하면 노쇼가 많은 것이고, 방문 → 등록이 약하면 체험 뒤 연락이 없는 것입니다. 해외 자료로 체험 뒤 소프트웨어로 자동 연락한 곳은 85.4%, 손으로 연락한 곳은 70.8%가 전환됐습니다. 단계마다 새는 곳을 막으면 같은 광고비로 등록이 두 배가 될 수도 있습니다.

단계별 새는 곳 찾기

광고 문의 깔때기

단계약하면 원인해결
문의 → 예약응답이 느림5분 회신, 첫 문장 준비
예약 → 방문노쇼예약 알림, 전날 안내
방문 → 등록체험 뒤 연락 없음당일·3일 뒤 자동 연락
등록 → 유지첫 달 이탈첫 달 관리 계획
전체기록 없음단계별 숫자 기록

이번 주 바로 하기

  1. 지난달 광고 문의 수를 센다
  2. 그중 체험 예약·방문·등록 수를 센다
  3. 가장 많이 빠지는 단계를 찾는다
  4. 그 단계 해결책 하나를 적용한다
  5. 다음 달 같은 숫자를 다시 센다

흔한 생각 등록이 적으면 광고가 나쁜 것이다.

실제로는 광고는 문의까지입니다. 문의 뒤의 단계가 약하면 어떤 광고도 효과가 없어 보입니다.

Q. 이 숫자 우리 센터에도 맞아요?

해외 공급사 계산 예시라 그대로 쓰긴 어려워요. 대표님 센터의 지난달 숫자로 깔때기를 직접 그려 보시는 게 가장 정확해요.

확인 문제

1. 체험 뒤 소프트웨어 자동 연락의 전환율(Gymdesk)은?

  1. 70.8%
  2. 75%
  3. 85.4%
  4. 95%
정답 보기

3번 85.4%

자동 85.4%, 수기 70.8%입니다.

단계마다 새는 곳을 막는 기능

  • 운톡 센터 문의·고객 메모로 문의 기록.
  • 예약 수업 체험 예약과 예약 알림.
  • Show/NoShow로 방문 확인.
  • 세그먼트 → 오토메이션으로 체험 뒤 자동 연락.
  • 전자계약서로 현장·원격 등록.

통화에서 이렇게

대표님, 광고 문의 100건이면 보통 등록이 3명에서 6명이래요. 해외 계산 예시지만 구조는 같아요. 광고 끊으시기 전에 문의, 예약, 방문, 등록 중에 어디서 제일 많이 빠지는지 같이 보실래요? 거기만 막아도 등록이 달라져요.
