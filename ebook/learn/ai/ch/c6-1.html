① 사전 학습: 세상의 글 읽기

대형 언어 모델은 어떻게 만들어지나 · 1/6

먼저 인터넷 글, 책, 코드 등 수조 단어로 '다음 단어 맞히기'를 해요. 이게 사전 학습이에요.

GPU 수만 개로 몇 달 동안 돌려야 하고, 돈이 수천억 원 넘게 들기도 해요. 전체 비용의 대부분이 여기 들어가요.

이렇게 만든 모델은 지식은 많지만 아직 '대화'는 못 해요. 질문을 하면 답 대신 비슷한 질문을 줄줄이 이어 쓰기도 해요. 이 단계의 모델을 기반 모델이라 불러요.

기억할 것

  • 수조 단어 · GPU 수만 개 · 몇 달
  • 결과물 = 기반 모델(아직 대화는 서툶)

깊이 읽기 1분

무엇을 읽히나

사전 학습 데이터는 주로 인터넷 웹페이지(공개 크롤링 데이터), 위키백과, 책, 논문, 코드 저장소, 대화 글 등이에요. 그대로 쓰지 않고 광고·중복·스팸·유해한 글을 걸러 내고, 질이 좋은 글의 비중을 높여요. 이 '데이터 다듬기'가 모델 품질을 크게 좌우해서 회사들이 가장 감추는 비법이기도 해요.

코드를 많이 읽힌 모델이 논리적 추론도 잘한다는 관찰이 있어 코드 비중을 높이는 경우가 많아요.

데이터가 바닥난다?

질 좋은 인터넷 글은 생각보다 많지 않아요. 연구자들은 사람이 쓴 공개 글을 다 써 버리는 때가 2020년대 후반에 올 수 있다고 추정했어요.

그래서 AI가 만든 문제와 풀이로 다시 AI를 가르치는 합성 데이터, 출판사·언론사와 계약한 유료 데이터, 영상·음성처럼 아직 덜 쓴 데이터가 중요해졌어요. 다만 AI가 만든 글만 계속 먹이면 품질이 점점 떨어진다는 '모델 붕괴' 연구도 있어서 조심스럽게 섞어요.

얼마나 드나

최상위 모델 한 번의 학습에는 수만 개의 GPU가 몇 달 동안 쉬지 않고 돌아요. 전기와 칩 비용을 합쳐 수천억 원 이상이 든다는 추정이 많고, 다음 세대는 조 단위가 된다는 말도 나와요.

이 비용 때문에 최상위 모델을 처음부터 만들 수 있는 곳은 세계에 손꼽을 정도예요. 나머지는 남의 기반 모델을 미세 조정하거나, 오픈 웨이트 모델을 가져다 써요. 2025년 딥시크가 '훨씬 적은 비용'을 내세워 충격을 준 것도 이 맥락이에요.
