에이전트·추론

낱말 10개

  • AI 에이전트 — 질문에 답만 하는 게 아니라, 목표를 받으면 스스로 계획하고 도구를 쓰며 여러 단계 일을 해내는 AI.
  • 도구 사용 — AI가 계산기, 검색, 프로그램 같은 바깥 도구를 불러 쓰는 능력.
  • MCP(모델 컨텍스트 프로토콜) — AI가 여러 앱과 데이터에 같은 방식으로 연결되게 하는 공개 표준. 2024년 말 앤트로픽이 내놓았어요.
  • 컴퓨터 사용(브라우저 에이전트) — AI가 화면을 보고 마우스·키보드를 움직여 사람처럼 프로그램이나 웹사이트를 다루는 기능.
  • 생각의 사슬 — 답을 바로 내지 않고 중간 풀이를 단계별로 쓰게 하면 어려운 문제를 더 잘 푼다는 발견.
  • 추론 모델 — 답하기 전에 속으로 긴 풀이(생각)를 먼저 하도록 강화 학습으로 훈련한 모델.
  • 추론 시점 계산 — 학습을 더 하는 대신, 답할 때 계산(생각)을 더 많이 써서 성능을 올리는 방법.
  • 벤치마크 — AI 실력을 비교하려고 정해 둔 공통 시험 문제.
  • 챗봇 아레나 — 사람들이 이름을 가린 두 AI의 답을 비교해 더 나은 쪽에 투표하고, 그 결과로 순위를 매기는 사이트.
  • 아카이브(arXiv) — 연구자들이 심사 전 논문을 무료로 먼저 올리는 사이트. AI 논문 대부분이 여기 먼저 나와요.
