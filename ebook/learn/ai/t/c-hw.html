칩·데이터센터

낱말 10개

  • GPU — 원래 게임 그래픽용으로, 단순한 계산 수천 개를 동시에 하는 칩. 딥러닝 계산에 딱 맞아 AI의 엔진이 됐어요.
  • CPU — 컴퓨터의 두뇌. 복잡한 일을 차례로 빠르게 처리하는 데 강해요.
  • 쿠다(CUDA) — 엔비디아 GPU로 일반 계산을 하게 해 주는 프로그래밍 환경. 2007년 공개.
  • HBM(고대역폭 메모리) — 메모리 칩을 아파트처럼 쌓아 GPU 바로 옆에 붙여, 데이터를 아주 빠르게 주고받게 한 메모리.
  • 메모리 벽 — 계산 속도는 빨라졌는데 메모리에서 데이터를 가져오는 속도가 못 따라가 생기는 병목.
  • NPU — 신경망 계산만을 위해 만든 전용 칩.
  • TPU — 구글이 자기 AI용으로 직접 설계한 칩.
  • 컴퓨트(계산 자원) — AI를 학습시키고 돌리는 데 드는 계산 능력. 대개 GPU 수와 사용 시간으로 말해요.
  • AI 데이터센터 — GPU 수만~수십만 개를 모아 놓고 전기와 냉각을 대 주는 거대한 건물.
  • AI 전력 문제 — AI 데이터센터가 늘며 전기 수요가 급증하는 문제.
