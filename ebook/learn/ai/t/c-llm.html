언어 모델

낱말 21개

  • 대형 언어 모델(LLM) — 엄청난 양의 글로 '다음에 올 말'을 맞히도록 학습한 거대한 신경망. 챗GPT·제미나이·클로드의 두뇌.
  • 자연어 처리 — 컴퓨터가 사람의 말과 글을 이해하고 만들게 하는 분야.
  • 토큰 — 언어 모델이 글을 읽고 쓰는 단위. 단어 하나, 또는 단어의 조각.
  • 토크나이저 — 글을 토큰으로 쪼개고 번호를 붙이는 도구.
  • 임베딩 — 단어나 문장을 뜻이 가까울수록 가까운 자리에 놓이는 숫자 좌표로 바꾼 것.
  • 트랜스포머 — 문장 속 모든 단어가 서로를 얼마나 봐야 하는지(어텐션)를 한꺼번에 계산하는 신경망 구조. 2017년 구글 논문에서 나왔어요.
  • 어텐션(주의 집중) — 단어 하나를 이해할 때 문장의 다른 단어 중 어디를 얼마나 참고할지 정하는 계산.
  • GPT — '미리 학습한, 글을 만들어 내는 트랜스포머'. 오픈AI 모델 시리즈의 이름이자 그 방식.
  • 사전 학습 — 인터넷 글 등 거대한 데이터로 '다음 단어 맞히기'를 하며 일반 지식과 언어 능력을 먼저 쌓는 단계.
  • 기반 모델(파운데이션 모델) — 큰 데이터로 미리 학습해 여러 일에 두루 바탕으로 쓸 수 있는 큰 모델.
  • 미세 조정(파인튜닝) — 미리 학습한 모델을 특정 일에 맞게 적은 데이터로 한 번 더 가르치는 것.
  • RLHF(사람 피드백 강화 학습) — 사람이 'A 답이 B 답보다 낫다'고 고른 결과로 모델이 더 도움 되고 안전하게 답하도록 다듬는 방법.
  • 컨텍스트 창 — 모델이 한 번에 읽고 기억할 수 있는 글의 최대 길이(토큰 수).
  • 지연 시간(레이턴시) — 질문을 넣고 답이 나오기 시작할 때까지 걸리는 시간.
  • 로라(LoRA) — 거대한 모델 전체를 고치지 않고, 작은 덧붙임 부품만 학습해 값싸게 미세 조정하는 방법.
  • 온도(temperature) — AI가 다음 말을 고를 때 얼마나 모험할지 정하는 값. 낮으면 뻔하고 안전하게, 높으면 다양하고 엉뚱하게.
  • 스케일링 법칙 — 모델 크기, 데이터 양, 계산량을 늘릴수록 성능이 예측 가능하게 좋아진다는 경험적 법칙.
  • 창발 능력 — 작은 모델에선 없다가 모델이 커지면 갑자기 나타나는 듯한 능력.
  • 증류 — 큰 모델(선생)의 답을 작은 모델(학생)이 따라 배우게 해, 작지만 꽤 똑똑한 모델을 만드는 방법.
  • 소형 언어 모델(SLM) — 수십억 개 안팎의 파라미터로, 폰이나 노트북에서도 돌아가게 만든 작은 언어 모델.
  • 온디바이스 AI — 서버가 아니라 스마트폰·노트북 같은 내 기기 안에서 돌아가는 AI.
