머신러닝

낱말 13개

  • 머신러닝 — 규칙을 사람이 짜는 대신, 데이터를 잔뜩 보여 주면 컴퓨터가 규칙을 스스로 찾게 하는 방법.
  • 데이터셋 — AI를 가르치려고 모아 둔 예제 묶음.
  • 라벨(정답 표시) — 데이터마다 붙인 정답. '이 사진은 고양이', '이 메일은 스팸'.
  • 학습(훈련) — 데이터를 보여 주며 AI의 속 숫자(가중치)를 조금씩 고쳐 실력을 키우는 과정.
  • 추론(사용) — 다 배운 AI에게 새 질문을 넣고 답을 받는 것. 즉 '쓰는' 단계.
  • 지도 학습 — 정답(라벨)이 붙은 데이터로 배우는 방식.
  • 비지도 학습 — 정답 없이 데이터 속 무리나 패턴을 스스로 찾는 방식.
  • 자기 지도 학습 — 데이터의 일부를 가리고 그걸 맞히게 해서, 사람이 정답을 달지 않아도 배우는 방식.
  • 강화 학습 — 해 보고, 잘하면 보상·못하면 벌을 받으며 스스로 요령을 익히는 방식.
  • 보상 — 강화 학습에서 '잘했다'를 숫자로 준 점수.
  • 과적합 — 연습 문제는 외워서 잘 맞히는데 새 문제는 못 푸는 상태.
  • 일반화 — 배운 것을 처음 보는 상황에도 잘 써먹는 능력.
  • 특징 — 판단에 쓰는 데이터의 성질. 집값이라면 넓이, 층, 역까지 거리.
