확인 문제 — 돈은 왜 회사로 갈까

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. '지분 10%를 50억 원에 투자받았다'. 회사 전체 값은?

  1. 50억 원
  2. 500억 원
  3. 5억 원
  4. 알 수 없다
정답 보기

2번 500억 원

50억이 10%니까 전체는 50 ÷ 0.1 = 500억 원.

2. '회사채 1,000억 원 발행'은?

  1. 투자 유치
  2. 빚을 낸 것
  3. 상장
  4. 인수
정답 보기

2번 빚을 낸 것

채권은 차용증이에요. 갚아야 하는 빚.

3. 새 투자를 받아 기존 주주의 지분 비율이 줄어드는 것은?

  1. 희석
  2. 회수
  3. 공시
  4. 상장
정답 보기

1번 희석

피자를 더 구워 새 조각을 주니 비율이 묽어져요(희석).
