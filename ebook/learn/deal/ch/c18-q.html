확인 문제 — 거품을 알아보는 눈

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. 큰 거품에 거의 빠지지 않고 있었던 것은?

  1. 금
  2. 빚(레버리지)
  3. 전쟁
  4. 세금 인상
정답 보기

2번 빚(레버리지)

빚이 오를 때 수익을, 내릴 때 투매를 키워요.

2. '이번엔 다르다. 예전 잣대로는 평가할 수 없다'는 말이 흔해지는 때는?

  1. 바닥
  2. 열광 단계
  3. 공황 뒤
  4. 언제나 같다
정답 보기

2번 열광 단계

값을 이익으로 설명할 수 없을 때 새 잣대가 나와요.

3. 거품이 꺼진 뒤에도 남는 것은?

  1. 아무것도 없다
  2. 기술·시설과 살아남은 회사
  3. 투자자의 수익
  4. 높은 주가
정답 보기

2번 기술·시설과 살아남은 회사

철도, 광케이블, 아마존처럼요.
