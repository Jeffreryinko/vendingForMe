확인 문제 — 회사를 사고판다 (인수합병)

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. 'A사, B사 인수 MOU 체결'. 지금 상태는?

  1. 인수가 끝났다
  2. 아직 확정이 아니다
  3. B사가 상장했다
  4. 인수가 깨졌다
정답 보기

2번 아직 확정이 아니다

MOU는 약혼 같은 것. 실사와 본계약이 남았어요.

2. 주가 10,000원인 회사를 '30% 프리미엄'에 산다면 주당 얼마?

  1. 7,000원
  2. 10,300원
  3. 13,000원
  4. 30,000원
정답 보기

3번 13,000원

10,000 × 1.3 = 13,000원.

3. 큰 회사끼리 합칠 때 정부가 경쟁이 줄어드는지 보는 심사는?

  1. 수요예측
  2. 기업결합(반독점) 심사
  3. 실사
  4. 공개매수
정답 보기

2번 기업결합(반독점) 심사

한국은 공정위, 미국은 FTC·법무부, EU는 집행위가 봐요.
