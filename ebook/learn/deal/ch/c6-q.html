확인 문제 — 주식시장에 오르다 (상장)

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. 상장 때 '신주'를 판 돈은 누구에게 가나?

  1. 기존 주주
  2. 회사
  3. 주관사
  4. 거래소
정답 보기

2번 회사

신주는 회사가 새로 찍은 주식. 판 돈은 회사로.

2. 'A사, 나스닥 상장 위해 S-1 제출'. 지금 상태는?

  1. 상장을 마쳤다
  2. 상장 절차를 시작했다
  3. 상장이 무산됐다
  4. 상장폐지됐다
정답 보기

2번 상장 절차를 시작했다

S-1은 상장 신청 서류. 아직 상장 전이에요.

3. 상장 뒤 대주주가 일정 기간 주식을 못 파는 것은?

  1. 수요예측
  2. 보호예수(락업)
  3. 공개매수
  4. 희석
정답 보기

2번 보호예수(락업)

자물쇠(lock-up)가 걸려 있어요.
