확인 문제 — 숫자로 회사 보기

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. 순이익 100억 원, 시가총액 2,000억 원인 회사의 PER은?

  1. 2배
  2. 20배
  3. 200배
  4. 0.05배
정답 보기

2번 20배

2,000 ÷ 100 = 20배.

2. 금리가 빠르게 오르면 스타트업 투자는 보통?

  1. 늘어난다
  2. 줄어든다
  3. 상관없다
  4. 금지된다
정답 보기

2번 줄어든다

안전한 곳에서도 이자가 나오니 위험한 투자가 줄어요.

3. 구독형 소프트웨어 회사에서 '이탈률이 낮다'는 것은?

  1. 고객이 잘 안 떠난다
  2. 적자가 크다
  3. 직원이 많이 나간다
  4. 주가가 낮다
정답 보기

1번 고객이 잘 안 떠난다

이탈(churn) = 구독을 끊는 고객 비율.
