확인 문제 — 재무제표 세 장 읽기

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. '흑자 도산'이 일어날 수 있는 까닭은?

  1. 이익과 현금이 다르기 때문
  2. 세금이 너무 많아서
  3. 주가가 떨어져서
  4. 배당을 안 줘서
정답 보기

1번 이익과 현금이 다르기 때문

장부에 이익이 나도 통장에 현금이 없으면 빚을 못 갚아요.

2. 자산 100억, 부채 70억인 회사의 자본은?

  1. 170억
  2. 70억
  3. 30억
  4. 100억
정답 보기

3번 30억

자산 = 부채 + 자본. 100 − 70 = 30억.

3. 감가상각을 EBITDA에서 다시 더하는 이유는?

  1. 세금을 줄이려고
  2. 현금이 실제로 나가지 않는 비용이라서
  3. 빚을 숨기려고
  4. 매출을 키우려고
정답 보기

2번 현금이 실제로 나가지 않는 비용이라서

기계 값은 살 때 이미 냈어요. 해마다 잡는 감가상각은 장부상의 비용이에요.
