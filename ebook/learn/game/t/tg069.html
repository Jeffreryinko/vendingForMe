LTV

Lifetime Value · 지표

이용자 1명이 게임을 떠날 때까지 쓸 총 돈

한 사람이 게임을 시작해서 그만둘 때까지 평균 얼마를 쓰는지 추정한 값임. 손님 한 명의 '평생 가치'임. LTV가 이용자 1명 데려오는 비용(CPI)보다 커야 장사가 됨. 리텐션과 ARPU로 계산함.

예

모바일 게임 마케팅은 'LTV > CPI'를 맞추는 게임이라는 말이 있음.

이어지는 말

CPI · ROAS · ARPU · 리텐션

확인 문제

1. 게임 마케팅이 남는 장사가 되려면?

  1. CPI = 0
  2. LTV > CPI
  3. LTV = 0
  4. LTV < CPI
정답 보기

2번 LTV > CPI

평생 가치가 획득 비용보다 커야 함.
