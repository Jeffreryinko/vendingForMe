K-팩터

K-factor (virality) · 지표

이용자 1명이 데려오는 새 이용자 수

한 사람이 친구 초대 등으로 평균 몇 명을 더 데려오는지 보는 숫자임. 1보다 크면 저절로 퍼지는 바이럴 상태임. 카카오톡 초대로 퍼진 '애니팡'이 대표 사례임. 광고비 없이 크는 게임의 비결임.

예

2012년 카카오톡 게임하기는 친구 초대·하트 보내기로 큰 바이럴을 만들었음.

이어지는 말

UA · 리텐션

  2. 광고 단가 상승
  3. 매출이 0
  4. 이용자가 줄어듦
