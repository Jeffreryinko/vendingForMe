라이선스 IP

Licensed IP · 사업·회사

남의 유명 IP를 빌려 만든 게임

영화·만화·다른 게임의 IP를 빌려 게임을 만드는 방식임. 이미 팬이 있어 이용자 모으기가 쉬움. 대신 IP 주인에게 로열티를 줘야 하고 마음대로 못 바꿈. 한국에선 중국 게임사에 IP를 빌려주고 로열티를 받는 일도 많았음.

예

위메이드는 '미르의 전설2' IP를 중국 회사들에 빌려주고 로열티 분쟁을 오래 벌였음.
