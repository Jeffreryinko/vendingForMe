콜라보

Collaboration event · 사업·회사

다른 IP·브랜드와 손잡은 이벤트

게임에 유명 애니·캐릭터·브랜드를 잠깐 들여오는 이벤트임. 양쪽 팬을 끌어와 매출과 화제를 동시에 만듦. 편의점·카페와 손잡은 굿즈 콜라보도 많음. 한정판 심리와 잘 맞물림.

예

데브시스터즈 '쿠키런: 킹덤'은 BTS 멤버를 쿠키 캐릭터로 만든 콜라보를 진행해 화제가 됐음.
