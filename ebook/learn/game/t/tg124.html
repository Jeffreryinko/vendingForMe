오가닉 설치

Organic install · 플랫폼·광고

광고 없이 스스로 찾아와 설치한 경우

검색, 입소문, 피처드로 광고비 없이 들어온 설치임. 광고로 들어온 '페이드(paid) 설치'와 구분함. 오가닉이 많으면 마케팅 효율이 좋아짐. 큰 광고가 오가닉을 끌어올리는 '후광 효과'도 있음.

예

TV 광고나 유명 스트리머 방송 뒤 오가닉 설치가 늘어나는 경우가 많음.
