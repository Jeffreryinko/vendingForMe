확인 문제 — 중국 읽기

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. 중국에서 가장 큰 권력을 가진 직함은?

  1. 국가주석
  2. 공산당 총서기
  3. 국무원 총리
정답 보기

2번 공산당 총서기

권력은 당에서 나와요. 같은 사람이 국가주석과 군사위 주석을 겸해요.

2. 미국의 '전략적 모호성'이 뜻하는 것은?

  1. 대만을 지켜 줄지 분명히 말하지 않는 것
  2. 대만 독립을 지지하는 것
  3. 중국과 동맹을 맺는 것
정답 보기

1번 대만을 지켜 줄지 분명히 말하지 않는 것

중국의 무력 사용과 대만의 독립 선언을 둘 다 막으려는 태도예요.

3. 중국의 '과잉 생산' 논쟁에서 문제가 되는 것은?

  1. 안에서 안 팔린 물건이 싸게 세계로 쏟아지는 것
  2. 중국이 수입을 너무 많이 하는 것
  3. 중국 인구가 느는 것
정답 보기

1번 안에서 안 팔린 물건이 싸게 세계로 쏟아지는 것

전기차·태양광·철강 등이 싸게 수출돼 다른 나라 산업이 타격을 받는다는 주장이에요.
