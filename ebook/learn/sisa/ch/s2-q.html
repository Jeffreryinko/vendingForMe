확인 문제 — 나라는 어떻게 굴러가나

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. 한국에서 대통령 탄핵을 최종 결정하는 곳은?

  1. 국회
  2. 대법원
  3. 헌법재판소
  4. 검찰
정답 보기

3번 헌법재판소

국회가 소추하고, 헌법재판소가 파면 여부를 결정해요.

2. '징역 5년 구형'은 누가 한 것?

  1. 판사의 최종 결정
  2. 검사의 요청
  3. 변호사의 주장
  4. 경찰의 발표
정답 보기

2번 검사의 요청

구형은 검사의 요청, 선고가 판사의 결정.

3. '연정 붕괴로 조기 총선'은 어떤 제도의 나라에서 흔한가?

  1. 대통령제
  2. 의원내각제
  3. 왕정
  4. 어느 나라나 같다
정답 보기

2번 의원내각제

의회 다수로 정부를 세우는 내각제에서 일어나요.

4. 한국 국회에서 대통령 거부권을 넘어 법을 통과시키려면?

  1. 과반(150석)
  2. 5분의 3(180석)
  3. 3분의 2(200석)
정답 보기

3번 3분의 2(200석)

재의결은 재적 과반 출석에 출석 3분의 2 찬성. 모두 출석하면 200석이 필요해요.

5. 어느 당도 과반이 안 되기 쉬워 연정이 흔한 선거제도는?

  1. 소선거구제
  2. 비례대표제
  3. 선거인단제
정답 보기

2번 비례대표제

정당 득표율대로 의석을 나누면 여러 당이 의석을 얻어 혼자 과반이 되기 어려워요.
