확인 문제 — 기술이 곧 안보

답을 골라 본 뒤 '정답 보기'를 누르세요.

1. 가장 앞선 반도체를 대부분 생산하는 곳은?

  1. 미국
  2. 대만
  3. 독일
  4. 인도
정답 보기

2번 대만

대만 TSMC. 그래서 대만 해협이 세계 경제의 급소예요.

2. '수출 통제'란?

  1. 수출에 보조금을 주는 것
  2. 첨단 기술·장비를 특정 나라에 못 팔게 막는 것
  3. 수입품에 세금을 매기는 것
  4. 환율을 고정하는 것
정답 보기

2번 첨단 기술·장비를 특정 나라에 못 팔게 막는 것

관세(세금)와 달리 아예 못 팔게 하는 조치.

3. 중국이 수출 제한 카드로 자주 쓰는 것은?

  1. 원유
  2. 희토류
  3. 밀
  4. 천연가스
정답 보기

2번 희토류

채굴·가공의 큰 몫을 중국이 쥐고 있어요.

4. AI 경쟁의 새 병목으로 꼽히는 것은?

  1. 전기와 전력망
  2. 종이
  3. 택배
정답 보기

1번 전기와 전력망

큰 데이터센터는 도시 하나만큼 전기를 써요. 칩이 있어도 전기가 없으면 못 돌려요.

5. 희토류·핵심 광물에서 중국이 가장 강한 단계는?

  1. 매장량
  2. 정제(가공)
  3. 소비
정답 보기

2번 정제(가공)

광석은 여러 나라에서 나지만 쓸 수 있게 정제하는 공장은 대부분 중국에 있어요.
