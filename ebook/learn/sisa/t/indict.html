수사 → 기소 → 재판

Investigation / Indictment / Trial · 꼭 알아 둘 말

수사는 조사, 기소는 검사가 재판에 넘기는 것, 선고는 판사의 결론. 기소됐다고 유죄는 아니에요.

비유하면

의심(수사) → 고발장 접수(기소) → 판정(판결). 판정 전까지는 무죄로 봐요(무죄 추정).

이렇게 나와요

'구속영장 청구', '불구속 기소', '징역 ○년 구형(검사 요청)'과 '선고(판사 결정)'를 구분하세요.

조금 더 자세히

수사(경찰·검찰이 증거를 모음) → 기소(검사가 재판에 넘김) → 1심 → 2심(항소) → 3심(상고) → 확정. 확정 전까지는 무죄로 추정해요.

구속은 벌이 아니라 도망·증거 인멸을 막으려는 조치예요. 불구속으로 재판받는 것이 원칙이에요.

실제 예

'피의자'(수사받는 사람) → '피고인'(재판받는 사람) → '수형자'(형이 확정된 사람). 기사에서 호칭이 바뀌는 순서예요.

헷갈리기 쉬운 점

'혐의'는 의심받는 내용일 뿐이에요. '기소 = 유죄'가 아니에요. '집행유예'는 유죄이지만 일정 기간 감옥에 보내지 않고 지켜보는 것이에요.
