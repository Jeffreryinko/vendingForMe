Windows Server에서 32비트 애플리케이션 지원이 중단됨

기술 · 중국·미국·베트남 · 기사 3개

마이크로소프트는 다음 버전의 Windows Server인 Windows Server 2028에서 32비트 Windows 애플리케이션이 64비트 운영체제에서 실행될 수 있도록 하는 호환 계층을 제거한다고 발표했습니다. 이는 새로운 운영체제가 기본적으로 WoW64 호환 계층을 포함하지 않음을 의미합니다.
