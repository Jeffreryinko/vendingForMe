웹 글도 넘김으로

종이 자판기에서 기사 원문으로 넘어가도 한 화면씩 넘겨 읽는 법

책갈피 하나를 만들어 두면, 아무 웹 글에서나 그 책갈피를 누를 때 광고·메뉴를 빼고 본문만 흰 바탕·검은 글자로 다시 깔아 넘김 방식으로 보여 줘요.

화면 오른쪽을 누르거나 왼쪽으로 밀면 다음, 왼쪽을 누르면 앞이에요. 음량·쪽 넘김 키도 되고, 위에 가− 가+(글자 크기), 전체화면, ✕(원래 화면)이 있어요.

1. 책갈피 주소 복사

책갈피 주소 복사

주소 직접 보기

지금 이 쪽에서 시험해 보려면: 넘김 보기 해 보기 (일부 브라우저는 여기서 바로 안 돼요. 책갈피로 만들면 돼요.)

2. 폰에서 책갈피 만들기

크롬 모바일 (가장 잘 돼요)

  1. 아무 쪽에서나 ☆(책갈피) 눌러 저장 → 책갈피 목록에서 그 책갈피 수정
  2. 이름을 넘김으로, 주소(URL) 칸을 지우고 복사한 주소 붙여넣기 → 저장
  3. 크롬 설정 → 동기화에서 북마크 켜기 (이북리더기 크롬도 같은 구글 계정)

파이어폭스

  1. 아무 쪽에서 ⋮ → ☆ 책갈피 → 수정, 이름 넘김, URL에 복사한 주소 붙여넣기 → 저장
  2. ⋮ → 설정 → 동기화(Firefox 계정)에서 북마크 켜기. 이북리더기 파이어폭스도 같은 계정으로 로그인하면 책갈피가 넘어와요.

3. 이북리더기에서 쓰기

  1. 읽을 글(종이 자판기의 '원문' 링크 등)을 연다
  2. 주소창을 누르고 넘김 이라고 친다 → 아래 추천 목록에 뜬 ☆ 넘김 책갈피를 누른다
  3. 본문이 넘김 화면으로 바뀌어요. 다 읽고 ✕ 누르면 원래 화면

책갈피 목록에서 바로 누르면 안 되는 브라우저가 많아요. 꼭 주소창에 이름을 쳐서 고르세요. 파이어폭스(안드로이드)는 버전에 따라 책갈피 실행이 막혀 있을 때가 있어요. 그러면 크롬이나 아래 EinkBro를 쓰세요.

더 편한 방법: EinkBro 브라우저

이북리더기 전용 무료 브라우저예요. 화면 가장자리 누르기나 음량(쪽 넘김) 키로 모든 웹 쪽을 넘김으로 보고, 읽기 모드·글자 크기·전체화면도 있어요. 책갈피 없이 늘 넘김이라 이북에서는 이게 가장 편해요.

  • 받는 곳: F-Droid의 EinkBro 또는 EinkBro 내려받기 쪽(arm64-v8a 고르기)
  • 북스는 설정에서 앱별로 쪽 넘김 버튼이 '한 화면만큼 스크롤'하게 바꿀 수도 있어요. 그러면 크롬·파이어폭스에서도 버튼으로 넘길 수 있어요.
