# 매일 업무 플래너

업무를 **성격별로 나누고**, 오늘의 **핵심 3가지**를 고르고, **시간을 붙이고**, 저녁에 **도장을 찍어 마감**하는 개인 플래너입니다.
서버 없이 GitHub Pages 하나로 돌아가고, 기록 맞추기·알림·공유는 시사 자판기와 같은 Supabase 프로젝트(vendingforme)를 씁니다.

- 주소: https://jeffreryinko.github.io/vendingForMe/planner/ (시사 자판기 저장소의 `planner/` 폴더)
- 로그인하지 않아도 그 기기에서는 바로 쓸 수 있습니다. 로그인하면 폰·PC가 이어지고 알림·구글 캘린더·링크 공유가 켜집니다.

## 하루에 세 번만 엽니다

| 언제 | 무엇을 | 어디서 |
|---|---|---|
| 떠오를 때 | **적기** — `N` 키(폰은 + 버튼)로 한 줄에 적습니다 | 빠르게 적기 |
| 아침 | **고르기** — 핵심 3가지를 고르고 시간을 붙입니다 | 오늘 화면 |
| 저녁 | **닫기** — 못 끝낸 블록을 내일로 넘기고, 한 줄 회고를 쓰고, 도장을 찍습니다 | 하루 마감 |

### 한 줄로 적는 법

```
내일 3시 견적서 보내기 #영업 @김대리 30분
```

| 적는 것 | 뜻 |
|---|---|
| `#영업` | 태그 (프로젝트·거래처 등) |
| `@김대리` | 담당 — 시킬 사람 |
| `!1` ~ `!6` | 업무의 성격 (1 긴급 … 6 중요) |
| `오늘` `내일` `모레` `금요일` `다음주 월요일` `11월 20일` `11/20` | 날짜. 시간이 없으면 **마감일**이 됩니다 |
| `3시` `오후 3시 반` `15:30` `10시~12시` | 시간. 적으면 그 날짜에 **시간 블록**까지 만들어집니다 (1~6시는 오후로 봅니다) |
| `30분` `1시간 30분` | 길이 |
| `금요일까지` | 마감일만 정함 |

### 쓰는 법

| 하고 싶은 일 | 방법 |
|---|---|
| 시간 붙이기 | 할 일 옆 시계 → 비어 있는 시간을 찾아 줍니다. PC는 할 일을 타임라인으로 끌어다 놓아도 됩니다 |
| 블록 옮기기·늘리기 | PC: 끌기(아래 가장자리 = 길이). 폰: 길게 누른 뒤 끌기 |
| 빈 시간에 바로 추가 | 타임라인의 빈 곳을 누르기 |
| 핵심 지정 | 할 일 옆 별, 또는 오늘 화면의 핵심 3 칸 |
| 남에게 넘긴 일 | 할 일을 열어 "넘겼어요 · 기다리는 중으로" → 답이 오면 완료 |
| 단축키 (PC) | `N` 빠르게 적기 · `T` 오늘 · `←` `→` 날짜 이동 |

### 돌아보기 (게임처럼)

- **점수**: 할 일 완료 10 · 핵심 달성 +20 · 핵심 3개 전부 +30 · 하루 마감 15
- **직급**: 인턴 → 애널리스트 → 어소시에이트 → 매니저 → 시니어 매니저 → 디렉터 → 파트너 → 시니어 파트너 → 매니징 파트너 → 레전드 (꾸준히 쓰면 매니저까지 약 반년, 레전드까지 약 4년)
- **쌓인 날들**: 한 칸이 하루. 많이 끝낸 날일수록 진하고, 마감 도장을 찍은 날은 동그랗습니다
- **한 주 돌아보기**: 어떤 성격의 일에 시간을 썼는지, 급한 일과 중요한 일의 균형, 태그별 시간, 한 줄 회고

## 기록은 내 것 — 옮기기 쉽게

설정 → 기록 내보내기·가져오기

| 형식 | 쓰임 |
|---|---|
| 전체 백업 (JSON) | 통째로 보관·복원. 다른 도구로 옮길 때의 원본 |
| 할 일 (CSV) | 엑셀·구글 시트·노션 표 |
| 시간 기록 (CSV) | 날짜·시작·끝·길이·분류·태그 — 시간 분석용 |
| 업무 일지 (Markdown) | 날짜별 핵심·블록·회고 — 노션·옵시디언에 붙여 넣기 |

넣을 때는 백업 파일을 불러오거나, **여러 줄을 붙여 넣으면** 한 줄에 하나씩 할 일이 됩니다(엑셀에서 복사한 칸도 그대로).

기록의 모양은 단순합니다. 한 항목 = `{ id, kind, …내용, u }` (`u` = 고친 시각).

| kind | 내용 |
|---|---|
| `task` | title, cat(0~6), tags[], who, due, note, st(open·wait·done), at, doneAt |
| `block` | date, start, end, title, cat, tags[], taskId, done, routine |
| `day` | date, top[할 일 id 최대 3], note(한 줄 회고), closedAt(마감 도장) |
| `settings` | 알림 시간, 루틴, 태그 색, 분류 이름 |

## 설치 (한 번만)

### 1. 올리기 — 끝남 (2026-11-11)
시사 자판기 저장소의 `planner/` 폴더에 올라가 있습니다. 파일을 고쳐 `main` 에 올리면 1~2분 뒤 반영됩니다.

### 2. Supabase — 끝남 (2026-11-11)
기존 `vendingforme` 프로젝트에 **추가만** 했습니다. 기존 표(`kv`)와 예약 작업(`vfm-*`)은 그대로입니다.

- 표 3개(`planner_items`, `planner_push_subs`, `planner_shares` — 모두 "각자 자기 것만" 보안), 비공개 칸(`planner_private`)
- Edge Function `planner` (JWT 검사 끔 — 함수 안에서 직접 확인)
- 예약 작업 2개: `planner-tick`(1분마다 알림 확인), `planner-tidy`(하루 한 번 청소)
- 다시 만들 일이 생기면: SQL Editor 에 [`supabase/schema.sql`](supabase/schema.sql) 전체를 Run (여러 번 실행해도 안전), 함수는 [`supabase/functions/planner/index.ts`](supabase/functions/planner/index.ts)
- 로그인 뒤 다른 화면으로 돌아가 버리면: **Authentication → URL Configuration → Redirect URLs** 에 `https://jeffreryinko.github.io/**` 를 추가

### 3. 구글 캘린더 켜기 (선택)
1. Google Cloud Console 에서 **지금 구글 로그인에 쓰는 프로젝트**를 열고 **Google Calendar API → 사용 설정**.
2. **OAuth 동의 화면**이 "테스트" 상태면 "프로덕션"으로 바꿉니다. 테스트 상태에서는 구글이 7일마다 연결을 끊습니다. 혼자 쓰는 앱이라 심사는 필요 없고, 연결할 때 "확인되지 않은 앱" 경고가 뜨면 고급 → 이동을 누르면 됩니다.
3. Supabase **Edge Functions → Secrets** 에 두 값을 넣습니다 (Authentication → Sign In / Providers → Google 에 있는 것과 같은 값).
   - `GOOGLE_CLIENT_ID`
   - `GOOGLE_CLIENT_SECRET`
   - 이 두 값이 없으면 연결은 되지만 1시간마다 "다시 연결"을 눌러야 합니다.
4. 플래너 → 설정 → Google 캘린더 → **연결**.

연결하면: 시간 블록이 분류 색 그대로 구글 캘린더에 올라가고(고치면 따라 바뀜), 구글 캘린더의 다른 일정은 타임라인에 점선으로 함께 보입니다. 구글 쪽 알림은 꺼서 올립니다(플래너 알림과 두 번 울리지 않게). 점심 같은 루틴 블록은 기본적으로 올리지 않습니다.

### 4. 폰에 설치 + 알림
- **아이폰**: Safari 로 열기 → 공유 → **홈 화면에 추가** → 홈 화면 아이콘으로 열기 → 설정 → 알림 → 이 기기에서 알림 켜기 (Safari 안에서는 알림이 안 됩니다)
- **안드로이드**: Chrome 으로 열기 → 메뉴 → **앱 설치** → 설정 → 알림 → 이 기기에서 알림 켜기
- 알림 종류: 블록 시작 N분 전 · 시작 시각 · 아침 요약(블록 수, 긴급·마감·기다리는 일 건수)

## 알아 둘 점

- **같은 주소(jeffreryinko.github.io)의 자판기들과 로그인을 함께 씁니다.** 한쪽에서 로그인하면 다른 쪽도 로그인된 상태가 되고, 플래너에서 로그아웃하면 자판기도 로그아웃됩니다.
- **누구나 자기 구글 계정으로 로그인하면 자기 플래너로 쓸 수 있습니다.** 기록은 계정마다 완전히 따로이며 서로 볼 수 없습니다(가족·동료에게 주소만 알려 주면 됩니다).
- **공유 링크**는 그 날짜의 블록 제목·시간·완료 여부와 핵심 3만 보여 줍니다. 할 일 목록·구글 일정·회고는 보이지 않습니다. 일정을 고치면 링크 내용도 따라 바뀌고, 설정에서 언제든 멈출 수 있습니다.
- **로그아웃하면 그 기기의 기록은 지워집니다**(서버에는 남아 있고, 다시 로그인하면 돌아옵니다).
- 두 기기에서 같은 항목을 고치면 **나중에 고친 쪽**이 남습니다.

```
index.html · app.css          화면 틀과 모양
js/main.js                    시작점, 할 일 목록, 타임라인(끌기)
js/sheets.js                  빠르게 적기·할 일·블록·핵심 3·하루 마감·공유·설정 창
js/review.js                  돌아보기
js/model.js                   규칙(할 일·블록·점수·통계·내보내기)
js/db.js                      기기 저장(IndexedDB) + 서버와 맞추기
js/cloud.js                   로그인·구글 캘린더·알림·공유 링크
js/util.js · js/ui.js         날짜 계산, 한 줄 해석, 공통 부품
sw.js · manifest.webmanifest  홈 화면 앱, 오프라인, 알림 표시
config.js                     Supabase 주소·공개용 키
supabase/schema.sql           표·보안·예약 작업
supabase/functions/planner/   알림 보내기·구글 토큰 갱신
```
