# AI 논문 · 쉬운 풀이 작업 순서 (편집장 루틴 07시 회차 안에서, 하루 최대 3편)

논문 목록·초록 번역·용어는 AI 로봇(GitHub Actions, 토큰 0)이 이미 모아 둡니다. 이 작업은 **고른 몇 편만** 초등학생도 알 수 있게 풀어 씁니다. 한 번 쓴 풀이는 저장돼서 앱이 계속 다시 써요(다시 만들지 않음).

## 1. 고르기
`python robot/easy_tools.py todo 3` → 오늘 풀 논문 (사용자 요청이 먼저, 그다음 Hugging Face 추천 ▲ 많은 순). 각 항목의 `title`·`abs`(초록)·`ksum`(기계번역 한 줄)을 읽습니다. 초록에 없는 사실은 쓰지 않습니다.

## 2. 쓰기 — 한 편의 모양
```json
{"id":"<논문 id 그대로>", "title":"<쉬운 한국어 제목>", "one":"<한 문장 요약>",
 "analogy":"<생활 속 쉬운 비유 2~4문장>",
 "must":["<꼭 알아야 할 것 1>", "<2>", "<3>"],
 "terms":[{"t":"<용어 한국어>", "en":"<영어>", "d":"<초등학생용 한 줄 뜻>"}],
 "why":"<왜 중요한지 2~3문장 — 우리 생활과 연결>", "limit":"<초록만 봐서 확인 안 되는 점 한 줄, 없으면 빈칸>"}
```
- 글투: 초등학교 5학년이 읽는다고 생각하고 짧은 문장, 영어 약자는 풀어서. 용어 3~5개.
- 과장 금지("혁명", "완전히 바꾼다" 등). 숫자는 초록에 있는 것만.

## 3. 저장
배열로 `/tmp/easy.json` 에 저장 → `python robot/easy_tools.py add /tmp/easy.json` (검사 통과 못 하면 고쳐서 다시). 요청으로 만든 것은 자동으로 '완료' 표시되고, 요청함 작업이 GitHub 이슈를 닫습니다.
