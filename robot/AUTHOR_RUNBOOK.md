# 이야기 도서관 · 작가 작업 순서 (클로드 예약 작업, 매일 새벽 4시, 5편)

목록(카탈로그)에 있지만 아직 안 쓴 이야기를 골라, **실제 문서(위키백과·브리태니커·위키문헌 등)를 읽고** 쉬운 한국어로 깊이별 재화(再話)를 씁니다. 읽는 사람은 시사상식을 넓히고 싶은 성인입니다. 사용자에게 질문하지 말고 끝까지 진행합니다.

## 0. 준비
1. `add_repo`(owner/`vendingForMe`, access=push) → clone. 폴더 `R`.
2. `python R/robot/iyagi_tools.py todo 5` → 오늘 쓸 5개 (`catId`·`orig`·`group`·`region`·`era`). 자료가 너무 적은 항목은 건너뛰고 `todo 8`로 더 받습니다.
3. 항목마다 WebSearch·WebFetch로 위키백과(한국어→영어 순) 등 신뢰할 만한 문서를 읽습니다. 문서에 없는 내용은 쓰지 않습니다.

## 1. 쓰기 — 한 편의 모양 (`data/iyagi/stories/_index.json` 의 문서와 같은 꼴)
```json
{"id":"w-<영문짧은이름>","catId":"c123","title":"<새 한국어 제목, 호기심 끄는 한 줄>","orig":"<카탈로그의 orig 그대로>",
 "group":"<카탈로그 group>","kind":"신화|설화|소설|인물 일화|사건|우화|만담|유래담 중 하나","region":"...","era":"...",
 "basis":"전승|기록|기록 · 일부 논쟁|창작","form":"축약 재화 · 위키백과 기준 · 재화 AI","mood":["따뜻한"],"tags":["..."],
 "hook":"<결말을 숨긴 2문장 도입>",
 "depths":{"d1":{"min":"1","body":["<3~4문단, 1분>"]},"d2":{"min":"4","body":["<5~7문단, 배경·인물·전개>"]},"d3":{"min":"9","body":["<8~12문단, 세부·논쟁·원전 표현>"]}},
 "parts":[{"t":"<대명사로 쓰이는 표현>","b":"<요즘 어떻게 쓰이는지 1~2문장>"}],
 "beyond":[{"t":"<이야기 너머 질문>","b":"<2~3문장>"}],
 "limit":"<문서로 확인되지 않는 부분 한 줄, 없으면 빈 문자열>","warn":"<폭력·죽음 등 주의 한 줄, 없으면 빈 문자열>",
 "links":[],"sources":[{"t":"Wikipedia, ‘…’","u":"https://…"}],"spoiler":false,"robot":true,"web":true,"lane":"web","why":"작가 로봇 · 매일 5편"}
```
- `mood`는 웃긴·기묘한·따뜻한·씁쓸한·비극적인·통쾌한 중 1~2개. `d3`는 자료가 충분할 때만.
- 끝에 붙는 "원전·재화" 표시는 앱이 `form`과 `sources`로 자동으로 보여 주므로 본문에 따로 쓰지 않습니다.
- 실존 인물의 사진은 넣지 않습니다. `art`는 비워 둡니다(앱이 표지를 그립니다).

## 2. 저장
1. 5편을 배열로 `/tmp/new_stories.json`에 저장 → `python R/robot/iyagi_tools.py add /tmp/new_stories.json` (검사 통과 못 하면 고쳐서 다시).
2. `cd R && git add data/iyagi && git commit -m "이야기: 새 이야기 5편(작가)" && git pull --rebase && git push`
3. 한 줄로 결과: 추가한 제목 5개, 건너뛴 항목과 이유.
